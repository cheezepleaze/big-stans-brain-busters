# Big Stan's Brain Busters

## Overview
A movie trivia connection game where you connect 3 actors/acresses via their movies. 

This is a project adaptation of this exact game found in [Stanley's Wet Goods](https://stanleys.la/) in Culver City. Their wording is as follows:

```
Name a separate film each actor has been in. 
The last word of the 1st title is the 1st word of the 2nd movie, etc.
> Ex: Tom Cruise, Will Smith, Natalie Portman
> Answer: A Few Good Men In Black Swan
```
